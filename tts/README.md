# Tabletop Simulator scripts

The read-only Lua snapshot script and the TTS-name → slug table for the Tabletop Simulator Adapter (spec A9, ADR 0004). Nothing here is ever added to the mod or the save.

- `snapshot.lua`: sent by the Advisor through TTS's External Editor API ("Execute Lua Code" on Global). It reports every game piece with its raw position and sends the Table Snapshot back as one JSON string with `sendExternalMessage`. It only reads, and it filters hidden information inside TTS: a card is named only face up or in the discard pile, decks only in the discard pile, Progress tokens never in a Great Library draw strip, nothing in a hand, and no GUIDs.
- `names.json`: the mod's object names → slugs. The mod's "Courthouse" is the Age III red card (`pretorium`) and its "Tribunal" is our `courthouse`.
- `places.json`: where things sit on the mod's table (pyramid grid for all three Ages, cities, Wonder columns, discard tile, token areas, track). `TableView` (engine/src/Advisor/Tts) turns a snapshot into places with it.
- `fixtures/ml-practice.snapshot.json`: the snapshot the script gives for the committed Age II save `docs/research/tts-mod/ml-practice.json` (generated by the tests in a fake table; rewrite with `UPDATE_TTS_FIXTURE=1 dotnet test`).

The Advisor embeds these files. `tools/tts-check.cmd` reads the live table once and compares it with the practice fixture.

The Advisor follows the table with these files (ticket 33): with "Follow the TTS table" ticked in the Advisor Window it sends `snapshot.lua` about once a second, waits until the table is settled (nothing held or moving, the same snapshot twice in a row), and reconciles it with the Move Log (`engine/src/Advisor/Tts/Reconciler.cs`): one explaining chain of Moves and Reveals is entered, several are offered as choices, anything else is a Desync listed place by place. Coins, the Conflict Pawn and looting tokens are only notes. `7wd-advisor --tts-file F` follows a snapshot saved in a file instead of the live table.
