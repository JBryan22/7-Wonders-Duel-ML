## Notes

- **Files:** `engine/src/Advisor/Tts/ExpectedTable.cs` (`SeatSides`, `ExpectedPiece`, `ExpectedTable.Pieces/Facts/SoftChecks`: the named expected-table projection, the AI-seat seam), `Reconciler.cs` (`Reconciler.Reconcile(state, ownerSeat, sides, snapshot)` → `Reconciliation` with `SyncStatus` Matches / OneChain / SeveralChains / Waiting / Desync, the chains, `NotOnTable` / `NotInLog` mismatches, soft-check `Notes`), `TtsAdapter.cs` (`SettledTable`, `ITableSource`, `TtsLinkSource`, `FileTableSource`, `TtsAdapter` polling). Server wiring in `AdvisorServer` (reconciles under the session lock, appends through `AdvisorSession.Enter(lines)`, saves, tells the advice service). Tests: `TablePainter` (lays a Game State out on a fake table and runs it through snapshot.lua), `TtsReconcileTests`, `TtsServerTests`.
- **Comparison = facts.** Expected table and snapshot are both turned into the same one-line facts ("White (P1)'s city: Baths", "Age II pyramid 3.1: a face-down card", "Discard pile: Walls", "Loose on the table near (0, -20): Baths"), so a Desync is a readable list. Inputs only: pyramid, cities, Wonders (built = card tucked), draft offer, discard, Progress tokens (board and areas), Statue of Liberty cards lying loose, anything loose. Never input: storage, hands, the bag, the Library draw strips. A removed Wonder may stay in its column. An Age the Engine has started but whose opening Reveal hasn't come is expected *empty* (not dealt yet).
- **Chain search:** depth-first from the current state, only Moves the table has evidence of (card in that player's city or on the discard pile, Wonder with a tucked card in that player's column, drafted Wonder in their column, token in their area; start choice and Statue keep/give always tried). Reveals come from the table: face-up card on the slot; a slot already empty → a card the log hasn't seen in a city/discard (flipped and taken between readings); 5 board tokens; 4 offered Wonders (offer + columns); Guild backs (+ empty slots if a Guild was already taken); the Statue's 3 cards anywhere. Who plays first is tried both ways. Limits: 4 Moves (Reveals between them free), 10 entries, 20,000 states (`ReconcileOptions`). Chains reaching the same Game State count as one (e.g. two flipped cards taken in either order). Several chains are ordered so the one the coins agree with comes first (coins never decide).
- **Waiting vs Desync:** a chain that stops at a Reveal the table can never show (owner's Great Library draw, a card nobody flipped, a flipped card tucked under a Wonder before it was read, Statue cards left face down) gives `Waiting` with what to enter by hand, plus any prefix chain as a one-click choice. Reveals the table *should* show (tokens, offer, Guild backs) are dead ends → Desync.
- **Invisible choices lag by design:** "P2 start me/opponent" and "liberty-keep" show nothing on the table until the next card is taken / the give; the log catches up then (or the owner clicks). Who discarded which card is also invisible; turn order normally settles it, at an Age start with an unseen start choice it becomes a choice.
- **Manual fixes win:** after Undo or rewind in the window, the table's current snapshot is *held*: a single chain is shown as a choice ("You changed the log by hand…"), not re-entered, until the table changes. `POST /api/tts/choose {index}` enters an offered chain (checked against the current log).
- **Server/API:** `POST /api/tts {follow, color}`, `GET /api/tts` (box + change counter; the page polls it each second while following and refetches `/api/state` when the counter moves), `StateResponse.Tts` (`TtsView`: status off / no-game / reading / matches / held / choices / waiting / desync, message, choices, mismatch lists, notes, last appended, connection problem, round-trip ms). Prefs in `tts.json` in the data folder (`Follow`, `Color` = owner's TTS colour, default White). `--tts-file F` follows a saved snapshot file (debugging, e.g. `runs\tts-live-snapshot.json`). Options `TableSource`/`TtsPolling` let tests inject a fake table.
- **For ticket 34:** seat: `SeatSides.ForOwner(session.Seat, color)` with the "You sit" select; auto-detect from `TableSnapshot.HostColor` and keep the select as the override. New game: following with no game shows "no-game"; `TtsLink.GameLoadedAt` is still unused. Restart catch-up: on start with Follow on, the first settled snapshot is reconciled against the resumed log, but only 4 Moves deep; a longer gap needs a catch-up mode (`ReconcileOptions` with a bigger `MaxMoves`/`MaxEntries`, ambiguity grows with discards and start choices). Promo: a promo Wonder in the offer when its box is unticked fails the draft Reveal (not in the pool) → Desync with "Wonder draft offer: The Messe" in `NotInLog`; detect it there (or from the pieces) for the one-click fix.

### Owner's live check (Windows desktop, about 15 minutes)

1. Start Tabletop Simulator and load the mod "7 Wonders Duel [ULTIMATE ed.]" as a new game (single player is fine; you will move both players' pieces). Close VS Code if it has the Tabletop Simulator extension running. Take a seat as **White**.
2. Double-click `tools\advisor.cmd`. In the browser, click **New game** (no promos), choose seat P1, Start.
3. In the right-hand box **Tabletop Simulator**, tick **Follow the TTS table** and check **You sit: White**. It should say "Connected · N ms per reading".
4. In TTS, set up as usual: the 5 Progress tokens face up on the board, then the mod's **Deal Wonders** button. Within about 2 seconds of letting go, the Advisor should offer two buttons, "reveal first P1 …" and "reveal first P2 …". Click the one for whoever plays first (or just let the first player take a Wonder: then it is entered by itself).
5. Draft all 8 Wonders, deal Age I, and play about 6 turns, taking cards for both players (build into the city, discard to the discard tile, build a Wonder by tucking a card under it). Flip newly uncovered cards as you normally would. Expected: each Move appears in the Move Log by itself a second or two after the table is still.
6. Mistake test: drop a card into the **wrong** player's city. Expected: a red **Desync** with two short lists. Move the card to the right city: the Desync disappears and the Move is entered.
7. Coin test: move one coin from Red's side to White's. Expected: only a line under **Soft checks** ("Coins: TTS shows … expected …"), no Desync. Move it back.
8. Tell Claude what happened at each step, and anything that was entered wrongly or not at all. If something looks wrong, save the table: close the Advisor's console window (the game is saved; only one program can listen to TTS at a time), then double-click `tools\tts-check.cmd`. It will say DIFFERENT (it compares with the practice save; that's expected) and saves the table to `runs\tts-live-snapshot.json`. Leave that file there, and the Move Log too (`%LOCALAPPDATA%\7wd\advisor\current.log`). Restart the Advisor afterwards with `tools\advisor.cmd`; it resumes the game.
