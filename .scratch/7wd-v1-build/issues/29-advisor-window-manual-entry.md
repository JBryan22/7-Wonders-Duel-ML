## Notes

- **Launch (owner):** double-click `tools/advisor.cmd` on Windows, or `tools/advisor.sh` on Linux. It runs `dotnet run --project engine/src/Advisor -c Release`, starts the server on http://localhost:7700 and opens the browser. Options: `--port N`, `--data DIR`, `--no-browser`. Close the console window (or Ctrl+C) to stop; nothing is lost.
- **Deviation from spec P9:** the program is `7wd-advisor` (project `Advisor`, its own exe), not `7wd advisor`. Same reason as `7wd-train` (ticket 24): the training loop rebuilds `engine/src/Cli` at every start, which fails while a `7wd.exe` is running, and the Advisor will be open for whole games while training runs.
- **Stack:** ASP.NET Core minimal API (`FrameworkReference Microsoft.AspNetCore.App`, no NuGet packages) + plain HTML/JS module in `engine/src/Advisor/web/` (no build step, no Node.js), served from the output folder; edit the files, then rebuild (or rerun the script) to see changes. Localhost only.
- **Design: the page holds no rules.** `BoardView` builds the whole view (pyramid from layout data, cities, track, tray, log) and every clickable action carries the exact Move Log line it enters; the page posts that line to `/api/entry`, which parses it with `MoveLog.ParseEntry` and replays. API: `GET /api/state`, `POST /api/new|entry|undo|rewind|abandon` (see `AdvisorServer`). Every answer is `{game, settings, error, notice}`; a refusal is a 400 with the reason and the unchanged view. Ticket 30's advice goes in the side panel's "Advice" box; ticket 32+ Adapters should call `AdvisorSession.Enter/Undo/RewindTo` (same lock as the server) rather than add a second path.
- **`AdvisorSession`:** the log is the source of truth: every entry, Undo and rewind builds a new entry list and replays it from scratch into a fresh `Game` (a failed entry leaves the game untouched). Undo = drop the last Move and every Reveal after it (before any Move: the last Reveal). Clicking log line n keeps lines 1..n. Flips named one card at a time are merged into one `SlotReveal` line while no Move comes between, so a hand-entered log reads like an Engine log (tested equal for the same seeds).
- **Seat and private Reveals:** the new-game screen asks the owner's seat (P1/P2 are labels only; "who plays first" is the first Reveal). The opponent's Great Library draw is appended automatically as `reveal P2 library ? ? ?` when due, and the owner then names the token they kept (any box token is legal); naming the opponent's draw, or redacting your own, is refused.
- **Friendlier refusals** on top of the Engine's checks: a slot that already shows a card, a card already revealed (the picker greys it out with where it is: "already in slot 0.0", "already in P2's city", "already in the discard pile"), a Guild in a non-Guild slot and vice versa, a card from the wrong Age. Engine messages lose the "Illegal move '...':" lead-in ("Can't discard theater: theater is covered").
- **Persistence:** default folder `%LOCALAPPDATA%\7wd\advisor` (Windows) / `~/.local/share/7wd/advisor` (Linux). `current.log` is rewritten (atomically) after every change; it is a normal Move Log plus a `# advisor seat=P1` comment, so `7wd replay current.log` works. `settings.json` remembers the promo boxes, start rule and seat. Starting a new game or "abandon" moves the old log to `games/<date_time>.log`. An unreadable `current.log` is moved to `games/` with a notice instead of stopping the server.
- **Reveal picker kinds** (`RevealView.Kind`): `first`, `tokens` (5 of 10), `draft` (4 of the pool, already-offered greyed), `guilds` (click 3 Age III slots on the pyramid), `slots` (click each pulsing card, filterable picker, Enter picks the first match), `library` (owner's 3 tokens), `returned` (Statue's 3 cards). Other Pending Decisions (draft, token, start, destroy, Mausoleum, Messe, Statue keep/give, Library pick) are tiles in the tray above the board, ready for ticket 31's % badges.
- **Verified:** launched with `tools/advisor.sh` on the desktop; entered a 75-line random game (seed 5) through the HTTP API and screenshotted Age III with headless Edge; then drove a fresh game in headless Edge over the DevTools protocol through the real clicks (new game with both promos, first player, tokens, both draft rounds, naming all 12 Age I cards in the picker, a card's action menu with disabled Wonders, Undo, rewind by log line) with no page errors.
