## Notes

- **Identities:** Grand Temples are cards 73-77 (`TempleDef.Card`, `PantheonData.TempleCards`/`TempleSet`, colour new `CardColor.Temple`, Age 3, no chain); Pantheon Wonders 14-15, tokens 10-12 as before. Base arrays unchanged: read any index with `GameData.Card/Wonder/Token(i)`, check with `IsCard/IsWonder/IsToken`, parse slugs with `AnyCardIndex/AnyWonderIndex/AnyTokenIndex` (base indices never load Pantheon data). `GameState` and `Payment`/`Scoring`/`MoveLog`/`StatePrinter` now use these.
- **Pools:** `GameState.WonderPool` adds `ExtraWonders` (14-16), new `TokenPool` (13), `TokensSetAside` = pool - set out - `TokensOutOfBox` (Pantheon: Enki's tokens and box tokens a player owns). Token Reveals outside the pool are refused (also in base games).
- **New module hooks** (`ExpansionModule`): `ExtraWonders`, `ExtraTokens`, `TokensOutOfBox`, `AgeThreeBacks` (Temples), `NextReveal(s, rng)` (called by `RandomChanceSource` once flips are revealed; `RandomChanceSource.Pick(rng, n, k)` is now internal static), `AdjustQuote` (end of `Payment.Quote`, not for chained cards), `PawnAdvanced` (each space in `AddShields`, after the capital check). `PantheonState` moved to its own file; `PantheonModule` holds the rules.
- **Log grammar** (`Log/PantheonLog.cs`, records in `Rules/Expansions/PantheonReveals.cs`): `reveal myth-tokens 1.0 greek ...` (5 slot/mythology pairs, after `reveal age1`), `reveal P1 divinities greek zeus hades` (private, `Audience` = player, deck order top first), `P1 divinity zeus 3` (`MoveKind.Divinity`, `Move.PlaceDivinity(d, space0)`, `.Divinity`/`.Space`; `DecisionKind.PlaceDivinity` with the Mythology in `PendingDecision.Wonder`), `reveal pantheon 1 aphrodite 2 baal ...` (every face-down space), `reveal offerings 1.0 offering-3 ...`, `reveal enki law economy`, `reveal temples 0.1 3.0 5.2` (`GuildPatternReveal(slots, Temples: true)`; must match `GameState.TempleBacks`). Age II order: `reveal age2`, pantheon, offerings, enki (only if Enki is in the Pantheon). Every Pantheon Reveal requires the flips first (`SlotsToReveal == 0`).
- **Tokens:** taken in `EndOfTurn` by `CurrentPlayer` for every token slot that is accessible (so before the next take-card and before a play-again turn; several tokens queue several decisions in slot order). Offering tokens are just held. A Mythology token pushes `PlaceDivinity` only if a space is empty.
- **State** (`PantheonState`, public read accessors): `SlotToken`, `MythologyTokens`/`MythologyTokenCount`, `OfferingTokens` (mask), `Space`/`IsFaceDown`/`Placer`, decks (`DeckSize`, `DeckCard(m, pos)` known or `Unknown`, `DeckKnownBy` audience bits, `SeenDivinities`), `HasDraw`/`Drawn(i)`, `Enki`, `Awaiting*`. The unchosen card goes on top known only by the drawer; a later draw must name known tops first.
