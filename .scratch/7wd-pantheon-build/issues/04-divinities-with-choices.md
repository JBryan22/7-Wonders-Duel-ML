## Notes

- **Moves and decisions** (appended after `Offer`): `MoveKind`/`DecisionKind` `Enki, Snake, Steal, Hades, Zeus, Anubis, Isis, Ra` (`PendingDecision.Wonder` = -1). `Move.Enki(token)` (`.Token`), `Snake/Steal/Hades(card)`, `Zeus(slot, age)` (slot in `Card`, Age in `Wonder`, `.Slot`; always slot-named so it can name a face-down card), `Anubis(wonder)`, `Isis(card, wonder)`, `Ra(wonder)`. Log: `P1 enki law`, `snake <card>`, `steal <card>`, `hades <card>`, `zeus 2.3`, `anubis <wonder>`, `isis <card> <wonder>`, `ra <wonder>`, and the public Reveal `reveal discarded <card>` (`ZeusDiscardReveal`). `PantheonLog.TryParse` now takes the state (Zeus's slot is of the current Age).
- **Flow:** `PantheonModule.Activate` pushes the effect's decision (`EffectDecision`) after the no-decision effects, then `FinishDecision`; a Divinity with nothing to choose from does nothing (no decision). `LegalEffectMoves` / `WhyEffectMoveIllegal` / `ApplyEffectMove` handle every kind > `Offer`; each ends with `FinishDecision` (so a token pick, a win, a Wonder's power or play again from Isis resolve as usual). Enki: the kept token via `TakeToken` (Law can pair), `EnkiTokens` = 0 so the other is back in the box. Nisaba: `PantheonState.SnakeCard` (`Snake`); `ExtraSymbols` gives Nisaba's activator the card's symbol too (opponent keeps it); `GainSymbol` runs, so pairs and supremacy count. Baal: card moves city to city (production updated). Hades: free build from the discard (Mausoleum-like). Anubis: `GameState.UnbuildWonder` (card to discard, removed Wonders untouched). Isis: `BuildWonder(..., free: true)` with the discarded card. Ra: `GameState.StealWonder`.
- **Zeus:** targets every occupied slot. A face-up card goes straight to the discard; a face-down one sets `PantheonState.ZeusSlot` (`AwaitingZeusDiscard`) with an **empty decision queue**, the module awaits `reveal discarded` (drawn from `UnseenPoolFor(slot)`, before the flips because the slot stays occupied until then), then `GameState.DiscardFromSlot` (discard + seen). Either way the player takes the slot's token (R2) via `TakeSlotToken` (shared with `EndOfTurn`); tokens on newly accessible slots go to them at `EndOfTurn`. **Ticket 07:** nothing private here, but the Determinizer/agents must handle a Reveal step with `PendingCount == 0`.
- **GameState changes (base behaviour identical):** `Build`, `BuildWonder` (new `free` parameter), `RemoveFromCity` are internal; new internal `TakeFromDiscard`, `DiscardFromSlot`, `UnbuildWonder`, `StealWonder`. `MaxMoves` 128 -> 320 (Isis: up to 63 discarded cards x 5 Wonders); the take-card Wonder buffer is sized `DraftSize` (Ra can give 5 Wonders). `PantheonState` gained `SnakeCard`, `ZeusSlot` (copied/compared/written; Pantheon bytes only); the printer shows the Snake.
- **Base unchanged:** determinism hashes, `FrozenGames/`, Encoding v1 manifest pass untouched.
