## Notes

- **Moves and decisions** (appended after `Ra`, same names in `MoveKind` and `DecisionKind`): `Gate`, `TheaterDeck`, `Theater`, `TheaterOrder`, `Minerva`, `NeptuneDiscard`, `NeptuneApply`. `Move.Gate/Theater/TheaterOrder(divinity)` (`.Divinity`), `Move.TheaterDeck(Mythology)` (`Card`), `Move.Minerva(space)` (space -9..9 like `ConflictPawn`, in `Card`, read with `.MilitarySpace`), `Move.NeptuneDiscard/NeptuneApply(token)` (`GameState.MilitaryToken` index, `.MilitaryToken`). Decision `Wonder`: `TheaterDeck` = the Theater's Wonder index, `Theater` = the Mythology, `TheaterOrder` = the Divinity being activated.
- **Log:** `reveal gate zeus baal enki isis mars` (public; each non-empty deck's top in Mythology order), `P1 gate zeus`, `P1 theater-deck greek`, `reveal P1 theater greek zeus hades aphrodite` (private, whole deck top first; record `TheaterReveal`, `Audience` = player), `P1 theater zeus` (public), `P1 theater-order hades` (**private Move**: the unused card put on top), `P1 minerva -3`, `P1 neptune-discard P1:5` / `neptune-apply P2:2` (token = side it lies on : coins). `reveal P1 divinities greek hades` now also allows one card (see below).
- **Private Move:** `Audience` moved from `Reveal` up to `LogEntry` (default -1); `MoveEntry.Audience` = player when `Move.IsPrivate` (only `TheaterOrder`). Ticket 07 must redact `TheaterReveal` and `theater-order` for the opponent (`reveal P2 theater ? ?`, `P2 theater-order ?`, not built) and treat the deck after a Theater as known to the activator only (`DeckKnownBy`).
- **Flow:** `PantheonModule.ApplyEffect` (split out of `Activate`) puts any Divinity in front of its activator, whatever brought it (Pantheon, Gate, Theater). Gate: `GatePending` -> `reveal gate` (tops become known to both, `DeckKnownBy` = 3; an unseen Enki revealed sets `AwaitingEnki`, so `reveal enki` comes before the choice) -> `gate <d>` takes the top off its deck; an Enki revealed but not chosen loses its tokens to the box (FAQ). Theater: new hook `ExpansionModule.WonderPower` (called from `BuildWonder`'s default branch) pushes `TheaterDeck` (if any deck has cards; works in Age I too) -> `TheaterPending` -> private reveal -> `theater <d>` (removed from wherever it is in the deck) -> if 2 cards remain, `theater-order` (put on top; both positions known to the activator only) -> then the effect. **The restack is chosen before the activated Divinity's effect** (no effect touches the decks, so the order is immaterial; it keeps the hand-held cards out of the state). Enki activated with no tokens on it (through the Theater, R3) sets `AwaitingEnki`: public `reveal enki`, then the `enki` decision.
- **Minerva (rules decision):** the rulebook (p. 13) says the pawn "would enter the space which contains the Minerva pawn, it instead stops moving", so the pawn stops **before** her space (no loot, no Poliorcetics for that step, remaining shields lost) and she leaves; any direction; on a capital she saves it once. The spec's "stops when it enters" wording was corrected in `docs/spec-pantheon.md` and expansions.md. New hook `ExpansionModule.PawnBlocked(s, position)`, checked before each step in `AddShields` (behind the null check). All 19 spaces are legal (her own pawn's space too). `PantheonState.Minerva` / `NoMinerva`.
- **Neptune:** discard any token left, then (if any is left) apply one from either side: the activator's opponent loses its coins (FAQ; treasury only, R7). New `GameState.RemoveMilitaryToken`. No token left: no decision.
- **Age I consequences of the Theater:** a deck can now hold 1 card when a Mythology token is taken: the token draws it alone (`DrawCount`, one placement, nothing returned); an empty deck queues no `divinity` decision. Zeus can now run in Age I (Theater) and take a Mythology token mid-turn: `divinity` placement now ends with `FinishDecision` (ends the turn if nothing is queued).
- `PantheonState` gained `GatePending`, `TheaterPending`, `MinervaSpace` (copied/compared/written; Pantheon bytes only); the printer shows Minerva.
