(P2 knows)"), the pending draw, Enki's tokens, the Snake. Tokens on structure slots (`SlotView.Token/TokenName`), Grand Temple backs (face `temple`), Minerva on the track (`ConflictView.Minerva`), each player's Mythology/Offering tokens, Astarte's coins and activated Divinities in the cities. Catalog: `CatalogView.Pantheon` (Temples, 2 Wonders, 3 tokens, 16 Divinities, own legend), so the base catalog is unchanged.
- **Entry:** every Pantheon decision is a tile row (`PantheonText.Decision`, labels in `PantheonText.Label`, also used by `AdviceTable.Label` and the AI banner). Pantheon Reveals are a new picker kind `fields` (`RevealView.Fields`, `FieldView(Key, Label, Options)`: one choice per field, line = prefix + "key value ..."): myth-tokens, own divinity draw, own theater, pantheon, offerings, gate; `reveal enki` uses the multi-pick (`tokens`), `reveal discarded` a single pick, `reveal temples` the Guild-back slot clicker. Options already seen are disabled with a reason; a known deck top is the only option for its position.
- **Redaction (manual entry):** `AdvisorSession.Replay` logs the opponent's private Reveals itself (`HiddenRevealDue`: the Library as before, plus `reveal P2 divinities greek ? ?` and `reveal P2 theater greek ? ? ?`); the opponent's placement is entered as `P2 divinity ? 4`, the restack `P2 theater-order ?` (only these are offered; naming them, or redacting your own draw/Theater, is refused). The session's state is the owner's view (= their Observation; tested equal to the true game's Observation after every line).
- **Against the AI (decision):** the session keeps the owner's log and the AI's private lines as **secrets** (`# advisor ai-secret <index> <base64 line>` comments in the saved log, so a glance doesn't spoil; dropped on takeback). `TrueGame()` = the log with secrets put back; `Deal()` deals Pantheon Reveals from the true game (the Gate/Pantheon Reveal/later draws must agree with the AI's hidden cards) and logs them as the owner sees them; `EnterAiMove` logs a private Move redacted. Base games keep the old path exactly (no secrets; Library drawn from the seed). The "AI played" line describes the redacted Move.
- **Network by Ruleset:** `AdviceSettings.PantheonAgent` / `7wd-advisor --pantheon-agent SPEC`; `AgentFor(rules)`: base games use `--agent`; Pantheon games use `--pantheon-agent`, else `--agent` if its network is Encoding v2, else `mcts` (the Pantheon Anchor). A v1 network as `--pantheon-agent` is refused at startup. Play against the AI: `/api/play/opponents` adds `pantheonOpponents` (Runs whose `run.json` says `encoding_version` ≥ 2, plus the built-ins); a v1 network is refused for a Pantheon game before it starts (`AiOpponent.Validate(rules)`).
- **Advice:** MCTS for every Pantheon decision (no Pantheon network yet); Pantheon reason tags (tokens taken, Astarte, activations, Gate/Theater follow-ups, Minerva, Snake, the 3 new tokens). Expected lines don't name Divinities decided by a chance step ("Place a drawn Divinity on space 3"). Measured: an Age II position, 800 sims, 0.25 s on the laptop.
